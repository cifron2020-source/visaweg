# DECISIONS

## 1. Сайт лежит в корне репозитория
**Дата:** 24.10.2026
**Решение:** файлы сайта (index.html, css/, js/, content/) лежат в корне, папки src/ нет.
**Причина:** GitHub Pages публикует сайт только из корня репозитория или из папки /docs. Из папки src/ публикация не работает.
**Не возвращать:** папку src/ из первоначальной схемы.

## 2. Тексты отдельно от кода
**Дата:** 24.10.2026
**Решение:** все тексты лежат в content/ru.json, de.json, en.json. В коде текстов нет.
**Причина:** чтобы добавить язык, достаточно добавить один файл. Код от языка не зависит.
**Условие:** во всех трёх файлах должны быть одинаковые ключи.

## 3. Без фреймворков
**Дата:** 24.10.2026
**Решение:** чистые HTML, CSS, JavaScript.
**Причина:** каждую строку должен уметь объяснить автор. Не нужна сборка, работает на бесплатном GitHub Pages.
