# Visaweg: BRIEF

## Цель
Многоязычный сайт (ru/de/en), который ведёт студента шаг за шагом
от идеи учиться в Германии до получения визы в консульстве.

## Аудитория
Студенты из России и русскоязычные абитуриенты.

## Технологии (не менять без записи в DECISIONS.md)
- Чистые HTML, CSS, JavaScript. Без фреймворков и сборщиков.
- Тексты только в content/*.json, в коде текстов нет.
- Хостинг: GitHub Pages.
- Данные пользователя только в localStorage, на сервер ничего не уходит.

## Правила
1. Каждая страница со сроками, суммами или требованиями содержит
   ссылку на официальный источник и дату проверки.
2. Сайт не заменяет консультацию. Пометка на каждой странице.
3. Персональные данные в ИИ не вводить (паспорт, документы).
4. Весь код должен быть объясним автором. Если не понятно, просим ИИ объяснить.
5. ИИ-ассистенты указаны в README (честная пометка).

## Роли ИИ
- Claude: архитектура, ревью, объяснение кода
- ChatGPT: тексты и проверка переводов
- DeepSeek: код и отладка (без личных данных)
- Gemini: анализ больших файлов

## Формат передачи
Конец сессии: ИИ заполняет шаблон в HANDOFF.md.
Всегда передавать полные файлы, а не фрагменты.
